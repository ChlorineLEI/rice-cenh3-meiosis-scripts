# rice-cenh3-meiosis-scripts
Scripts for analyzing CENH3 loading and epigenetic data in rice meiosis
CGmapTobw.py: turing .CGmap(bismark) to .bw
readcounts.py: calculating mapped read counts depth to genome from bam files
top_10_related_genes.R: R script to calculate the most 10 realted genes by expression level of the given list.
